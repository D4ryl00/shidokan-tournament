# Étape 8 : Aides à l'écran — plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** chaque onglet et chaque section de l'app affiche une phrase d'aide en mots simples et un bouton ⓘ qui ouvre une aide complète ; les passages d'âge de la grille sont écrits en clair.

**Architecture:** tous les textes vivent dans un seul fichier de données (`src/web/help.ts`), relisible d'un coup et testé unitairement ; trois petits composants (`src/web/components/Help.tsx`) les affichent ; chaque page les place sous ses titres. Aucun changement serveur.

**Tech Stack:** React 19, Mantine 8 (`Modal`, `ActionIcon`, `Title`, `Text`, `Fieldset`), Vitest, Playwright (Chrome).

**Spec:** `docs/superpowers/specs/2026-10-22-ordre-de-passage-et-aides-design.md` (Partie 2).

## Global Constraints
- Interface en français ; vouvoiement à l'impératif (« Tapez… », « Choisissez… »), comme le reste de l'app.
- Aide courte : **une phrase, 160 caractères au plus**, terminée par un point, visible sans clic sous le titre de la section.
- Aide complète : s'ouvre d'un clic sur ⓘ ; étapes une par une, sens des badges et couleurs, cas particuliers.
- Pas de jargon ni de codes internes dans les textes (ni « C : », « D : », « registration », « bracket », « seed », « API »…).
- Exemple fixé par la spec, à reprendre mot pour mot pour la pesée : « Tapez le poids lu sur la balance puis Entrée : le combattant est marqué présent. »
- Passages d'âge : libellés **« Toujours permis »** (type C) et **« Seulement si le mélange seniors / vétérans est activé »** (type D).
- Les aides n'apparaissent jamais à l'impression (classe `no-print` de `src/web/print.css`).
- Tous les tests restent verts : `npm run typecheck && npm test && npm run test:e2e`.

## Review Focus
- **Impression** : une feuille imprimée (tableaux, pesée, podiums) ne doit contenir ni aide ni ⓘ → test Task 3 (média `print`).
- **ⓘ dans un formulaire de réglages** : l'ouvrir ne doit ni enregistrer ni modifier les réglages → test Task 3 (aucune requête `PATCH`).
- **ⓘ dans la fenêtre de résultat** : fermer l'aide (Échap) ne doit pas fermer la saisie du résultat en cours → test Task 2.
- **Lecteur d'écran / clavier** : chaque ⓘ est un vrai bouton nommé « Aide : <titre> » → tests Task 2 et 3 via `getByRole('button', { name: … })`.
- **Texte périmé** : l'aide des sauvegardes doit dire ce que fait le serveur (200 sauvegardes gardées), pas l'ancien « 30 dernières » → test Task 1.

- [ ] **Step 1 : Écrire les tests** (`tests/web/help.test.ts`)

```ts
import { COMPETITION_TABS } from '../../src/web/tabs.js';
import { HELP } from '../../src/web/help.js';

test('chaque onglet a son aide', () => {
  for (const t of COMPETITION_TABS) expect(HELP[t.path as keyof typeof HELP], t.path).toBeDefined();
});
test('aides courtes : une phrase de 160 caractères au plus, terminée par un point', () => {
  for (const [id, h] of Object.entries(HELP)) {
    expect(h.short.length, id).toBeLessThanOrEqual(160);
    expect(h.short.trim().endsWith('.'), id).toBe(true);
    expect(h.details.length, id).toBeGreaterThan(0);
  }
});
test('pas de jargon ni de codes internes', () => {
  const all = Object.entries(HELP).map(([id, h]) => [id, [h.title, h.short, ...h.details.flat()].join(' ')] as const);
  for (const [id, text] of all) expect(text, id).not.toMatch(/\b[A-H] :|\b(registration|bracket|seed|null|undefined|API|weight_out)\b/i);
});
test('pesée : phrase de la spec', () => {
  expect(HELP.pesee.short).toBe('Tapez le poids lu sur la balance puis Entrée : le combattant est marqué présent.');
});
test('passages d’âge : libellés en clair', () => {
  const text = HELP['grille.passages'].details.flat().join(' ');
  expect(text).toContain('Toujours permis');
  expect(text).toContain('Seulement si le mélange seniors / vétérans est activé');
});
test('sauvegardes : le nombre gardé est celui du serveur', () => {
  expect(HELP['podiums.sauvegardes'].details.flat().join(' ')).toContain('200');
});
```
